# PeerLift

A GitHub Pages-ready website for a Skill-Based Student Community Help System.

## Features

- Responsive student-focused interface
- Filter requests by skill category
- Post requests with validation
- Offer-help feedback
- Browser-side data storage (local storage)
- No database or installation needed

## Publish with GitHub Pages

1. Create a repository on GitHub.
2. Upload every file in this folder to its root.
3. In **Settings → Pages**, select **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. GitHub will give you a live website link.
